# 训练方法边界：Prompt/RAG、SFT/LoRA、DPO、蒸馏与 Agentic RL

> 目标：把「改造模型行为」的五条路——不训练（Prompt/RAG）、监督微调（SFT/LoRA）、偏好优化（DPO）、蒸馏、强化学习（Agentic RL）——从**数据、目标、成本、风险、评测要求**五个维度摆清，给出「什么时候该选哪条、什么时候干脆不训练」的决策框架。

---

## 1. 阅读前术语表

| 术语 | 说明 |
|---|---|
| Prompt/RAG | 不改权重，靠提示词工程 + 外部知识检索 |
| SFT | Supervised Fine-Tuning：用输入-输出对监督微调 |
| LoRA | 低秩适配，只训练少量低秩矩阵，冻结主干 |
| DPO | Direct Preference Optimization：用偏好对直接优化，无需 reward model |
| 蒸馏 | 用教师模型生成数据，把能力迁移到小模型 |
| Agentic RL | 对 agent 的多步行为（工具、轨迹）做强化学习 |
| 灾难性遗忘 | 微调后模型忘掉原有能力 |
| Reward Hacking | 模型钻奖励函数空子而非真正解决问题 |

---

## 2. 五条路的对照总表

| 维度 | Prompt/RAG | SFT/LoRA | DPO | 蒸馏 | Agentic RL |
|---|---|---|---|---|---|
| **数据** | 无训练数据，外部文档/示例 | 输入-输出演示对 | 偏好对（chosen vs rejected） | 教师生成数据 | 奖励信号（可验证结果/轨迹） |
| **目标** | 推理时注入知识 | 模仿演示行为 | 学会「哪个更好」 | 迁移教师能力 | 优化多步行为/工具使用 |
| **成本** | 极低（无训练） | LoRA 低 / 全参 SFT 中 | 中（需偏好数据，无 RM） | 中（需先有教师） | 高（环境 + 采样 + 训练） |
| **风险** | 幻觉、上下文膨胀、检索错 | 过拟合、遗忘、数据质量 | 长度偏置、reward hacking | 受教师能力封顶 | 不稳定、reward hacking、成本失控 |
| **评测要求** | 检索质量 + 端到端任务 | held-out 任务 + 回归 | win-rate vs 基线 + 质量 | 与教师差距 | 轨迹成功率 + 工具正确性 + 安全 |

---

## 3. 逐条展开

### 3.1 Prompt/RAG：不训练，先改推理

- **数据**：无需训练数据；把知识放在外部文档里，推理时检索注入。
- **目标**：让模型「临时知道」它没学过的东西，或约束其行为。
- **成本/风险**：几乎零训练成本，但**推理成本上升**（检索 + 更长上下文），且引入**幻觉**（检索到错的证据）、**上下文膨胀**（文档 02）、**检索噪声**三类新风险。
- **评测**：先评检索质量（召回/精确），再评端到端任务；否则分不清「检索错」还是「模型错」。
- **适用**：知识需要**频繁更新**、或只需**临时约束**、或不想动权重时。**绝大多数 Agent 改造应从这一步开始**。

### 3.2 SFT / LoRA：用演示把行为「印」进去

- **数据**：高质量的输入-输出对（演示）。
- **目标**：让模型**稳定模仿**某种格式/风格/行为。
- **成本/风险**：LoRA 只训低秩矩阵、成本低、可插拔；全参 SFT 成本中。风险是**过拟合**（数据覆盖不到就退化）与**灾难性遗忘**（学了新行为忘了旧能力）。
- **评测**：held-out 任务集 + **回归测试**（确保旧能力没掉）。
- **适用**：行为有**清晰的、可枚举的正确答案**（格式转换、工具调用格式、领域风格）。**适合「让模型稳定输出某种格式」而非「学会推理」**。

### 3.3 DPO：用偏好对学会「哪个更好」

- **数据**：偏好对（同一 prompt 的 chosen vs rejected 两个回答）。
- **目标**：让模型输出更接近「被偏好」的回答，**无需训练 reward model**（对比 PPO 省一半）。
- **成本/风险**：省 reward model，但数据标注（哪个更好）有成本。风险：**长度偏置**（偏好长回答）、reward hacking（钻「看起来好」的空子）。
- **评测**：win-rate（对基线胜率）+ 质量评测，注意**长度偏置要控制**。
- **适用**：目标是「更好/更符合偏好」而非「记住新知识」，且能便宜地得到偏好对。**对齐风格/质量时比 SFT 更直接**。

### 3.4 蒸馏：把大模型能力压进小模型

- **数据**：教师模型（大模型）生成的数据。
- **目标**：让小模型**逼近教师**的行为/推理能力。
- **成本/风险**：省的是**部署**成本（小模型跑得快），花的是**教师**成本（要先有大模型生成数据）。风险：**受教师能力封顶**，教师错学生也错。
- **评测**：与教师的能力差距（gap），以及相对同规模非蒸馏模型的提升。
- **适用**：**部署成本是主矛盾**时——用一个便宜小模型承载大模型的部分能力（DeepSeek-R1 蒸馏到 Qwen/Llama 小模型，13-w/03）。

### 3.5 Agentic RL：用奖励优化多步行为

- **数据**：**奖励信号**——可验证的结果（任务成功与否）或轨迹反馈，而非固定标签。
- **目标**：优化**多步、带工具调用**的 agent 行为（何时检索、何时调工具、怎么规划）。
- **成本/风险**：最高——需要环境/模拟器 + 大量采样 + 训练。风险：**训练不稳定**、reward hacking（钻奖励空子）、成本失控。
- **评测**：**轨迹成功率**（整条 agent 轨迹对不对，不只最终答案）+ 工具调用正确性 + 安全。
- **适用**：行为**没有唯一正确答案、只能靠结果好坏评价**（多步规划、工具编排）。Kimi K2.5 的 PARL、k1.5 的长上下文 RL（13-w/04）都是这条路。

## 4. 决策框架：不训练 / LoRA / SFT / DPO / RL 怎么选

按三个问题依次判断（这也是第 14 周「模型改造 ADR」的结构）：

1. **问题能用「不训练」解决吗？**
   - 知识需要更新/临时约束 → **Prompt/RAG**（先试这个）。
   - 行为只是「格式/风格」且可枚举 → 进入问题 2。
   - 行为需要「更好/推理/多步」 → 进入问题 3。

2. **有清晰的演示对 or 偏好对吗？**
   - 有明确正确答案的演示对 → **SFT/LoRA**（想省成本用 LoRA）。
   - 只有「哪个更好」的偏好对 → **DPO**。

3. **目标是「能力迁移」还是「优化探索性行为」？**
   - 要把大模型能力压进小模型、省部署 → **蒸馏**。
   - 要优化多步、探索性的 agent 行为、只能靠结果评价 → **Agentic RL**。

**三条铁律**：

- **不训练 > 训练**：能靠 Prompt/RAG 解决就别训练——训练有数据、遗忘、评测成本。
- **数据形态决定方法**：演示对 → SFT/LoRA；偏好对 → DPO；奖励信号 → RL；教师数据 → 蒸馏。**先看手里有什么数据**。
- **评测要求随方法升级**：从「检索质量 + 任务」到「held-out + 回归」到「win-rate」到「轨迹成功率 + 安全」，方法越强、评测越要防 reward hacking 与遗忘。

---

## 5. 本文结论

五条路是「改造模型行为」的**递增梯度**：Prompt/RAG（不训练）→ SFT/LoRA（模仿演示）→ DPO（学偏好）→ 蒸馏（迁移能力）→ Agentic RL（优化探索性多步行为）。选型的核心是**数据形态**（演示/偏好/奖励/教师数据）和**成本-风险**（训练越重、越要防遗忘与 reward hacking）。绝大多数情况应**先用 Prompt/RAG 顶**，只有「最高档模型也持续失败、且失败可复现」时（文档 04），才进入训练决策——这正是第 14 周 ADR 要写清楚的那份「不训练/LoRA/SFT/DPO/RL」论证。
