# 7 分钟可重复演示与备用录屏方案

## 演示前检查（30 秒）

运行 `python3 ci/run_ci.py`，确认终行出现 CI Gate 通过。只使用合成租户、示例域名和生成数据；关闭通知并清空终端历史，不展示环境变量。

## 主演示（约 7 分钟）

1. 0:00–0:45：说明业务问题、人工假设基线和“不联网、不发布”的自动化边界。
2. 0:45–1:30：打开 README 架构图，指出 PEP、单工作流、Evidence、Checkpoint、HITL 和 Eval Gate。
3. 1:30–2:30：按第 15 周 README 启动服务，提交两条有冲突 `claims` 的来源，展示报告中的 `[S1]/[S2]` 与冲突段。
4. 2:30–3:20：提交无相关证据任务，展示拒答；提交含外部恶意指令的来源，展示隔离。
5. 3:20–4:20：提交 `require_approval=true`，在实例 A 暂停，在实例 B 审批恢复，展示共享 Checkpoint。
6. 4:20–5:10：打开 `results/security-fault.json`，说明 21 个安全和 10 个故障场景；展示 Trace 无正文。
7. 5:10–6:10：打开消融结果，解释双路代理无收益、硬截断破坏证据、人工路由是安全边界。
8. 6:10–7:00：运行发布演练，展示一个 94% 候选被 CI 阻断，以及另一个离线通过的候选在 Canary 降到 94% 后回到 v1；最后给出“有限上线”结论。

## 备用录屏

录制 1080p、7 分钟、无剪辑版本，画面只包含仓库、终端和本地服务。开头显示 commit ID 与日期，结尾显示 `results/` 四个文件哈希。另保留 90 秒降级版：架构图 → 冲突报告 → Eval Gate → 回滚结果。录制前运行公开材料扫描；视频不得出现真实姓名、邮箱、Token、浏览器标签或生产 URL。
