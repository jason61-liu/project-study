# 模拟面试一：Agent 架构与可靠性

时长：45 分钟；主题：设计可上线深度研究 Agent；结果：42/50。

## 题目与追问

1. 先定义用户和成功：回答明确研究员、授权语料、引用正确率、一次通过率、时间、升级率和成本；主动排除自动发布。得分 10/10。
2. 画主架构：给出 PEP、单工作流、检索、Evidence、验证、Checkpoint、HITL、Trace 和 Eval Gate。追问为什么不用多 Agent，引用消融成本翻倍、延迟约增加 58% 且质量不变。得分 9/10；应更早说明搜索供应商边界。
3. 来源冲突与注入：说明外部正文无指令权限、结构化冲突并列、引用集合校验、无法裁决就升级。得分 9/10。
4. 中断与重复副作用：说明 CAS、幂等键、Effect Ledger、UNKNOWN 对账、Checkpoint 和 fencing。得分 8/10；当前代码没有真实外部 Effect Ledger，只是设计答案。
5. 发布与运营：说明 Offline Gate、Shadow、5% Canary、自动/人工回滚、反馈抽样与 holdout。得分 6/10；缺真实用户 KPI 和跨区域演练。

## 面试官式反馈

优势是先讲业务边界，能用本项目消融拒绝不必要复杂度，也能区分文本正确和 Outcome 正确。主要缺口是真实 OAuth、独立 Sandbox、外部副作用对账和标准 Benchmark 均停留在参考实现或计划。重答时必须主动把“已实现、模拟、尚未验证”分开。
