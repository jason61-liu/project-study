# 已知限制、残余风险与失败样本

| 限制 / 风险 | 当前控制 | 正式上线前动作 |
|---|---|---|
| 合成评测过于简单 | 明确标注、3 Trial、Grader 修复记录 | 200 个真实影子任务、双人标注、固定 holdout |
| 只有 tau3 契约 Smoke，无能力成绩 | v1.0.1 五题、provenance、Trace 和 Gold replay 标签 | 用真实 Agent/用户模拟器固定模型快照运行官方协议 |
| 抽取式报告不等于深度综合 | 引用和冲突确定性可验 | 接真实模型并做忠实度、充分性、人评 |
| SQLite 单写者瓶颈 | WAL、CAS、容量阈值 | PostgreSQL、RLS、备份恢复、连接池 |
| 本地 Sandbox 非强隔离 | 无 Shell、白名单、超时、临时目录、Linux rlimit | 独立微虚机/容器，默认断网、无 Secret、销毁验证 |
| TokenVerifier 不做签名验证 | 明确位于 IdP 后的二次 PEP | 接真实 JWKS、时钟偏差、撤销源和强认证 |
| 注入检测可被改写绕过 | 外部正文始终无指令权限 | 内容隔离、最小工具权限、红队持续回归 |
| OTel 只是本地兼容形状 | 无正文 Trace、可查询元数据 | 正式 SDK/Collector、采样、后端租户 ACL |
| 反馈污染 | 去重、脱敏、双人审批、holdout 隔离 | 数据删除演练、标注一致性、来源权重 |

当前失败样本的高价值类别是引用缺失、来源冲突、无关答案和上下文压缩丢失事实。每个样本必须保存输入哈希、环境版本、失败类型、Trace 引用、人工裁决和修复版本；不得把用户自由文本未经清洗直接加入训练或长期记忆。
