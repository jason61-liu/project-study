# 用户反馈与失败回流闭环

反馈分类为正确、引用缺失、证据冲突、无关、安全和过慢；人工升级原因独立记录为高风险、来源冲突、证据不足和策略复核。Online KPI 包括成功率、任务时间、升级率、返工错误成本、单位成功成本以及安全硬门槛。

抽样策略：普通成功任务抽 5%，所有失败和高风险任务抽 100%。失败样本先脱敏和规范化去重，再由两名评审确认标签；固定 Regression holdout 永不进入训练。新增样本保留 provenance、版本与删除能力。

模拟闭环结果保存在 `results/feedback-loop.json`：Offline 成功率从 90% 到 96%，Online 从 86% 到 96%，方向一致。模拟数据只能验证计算和回流协议，不能作为真实产品收益。
