# AI Agent 与模型推理岗位市场调研

> 统计日期：2026-07-17  
> 目标人群：硕士、10 年工程经验、近 2 年 Agent 学习与实践  
> 目标岗位：资深 AI Agent / 大模型应用架构与工程岗位

## 样本方法

- 样本规模：137 个去重岗位，其中 BOSS 直聘 116 个（84.7%），猎聘 21 个（15.3%）。
- 城市范围：北京、上海、深圳、杭州、广州、成都、苏州、武汉、西安、南京，共 10 个城市。
- 纳入：职位标题或公开摘要明确包含 AI Agent、智能体、大模型应用、Agentic 平台或模型 Agent 核心能力。
- 排除：纯推荐、纯计算机视觉、纯预训练、纯芯片/算力基础设施，以及同一岗位的跨页面重复项。
- 证据分级：`full_detail` 为公开完整描述，`public_summary` 为公开摘要，`title_only` 为仅有标题和基本字段。能力统计只使用前两档，共 122 个岗位；15 个 `title_only` 岗位只参与城市、经验和学历分布。
- 编码规则：只统计公开描述明确出现的能力，因此结果是“最低出现率”，不是对完整 JD 的穷尽统计；一个岗位可以命中多个能力类别。
- 资深子样本：经验明确为 5 年以上，或标题包含资深、高级、架构师、专家、Tech Lead、组长、P6，共 46 个岗位；其中 38 个有描述或摘要，可用于能力统计。
- BOSS 主要入口：[上海](https://m.zhipin.com/zhaopin/42555746a85eb0741HB43di7GQ~~/)、[北京](https://m.zhipin.com/zhaopin/5589efcb37983f380nB_3Ny0FA~~/)、[深圳](https://m.zhipin.com/zhaopin/61b3aefe7b718e280nBy29m6GQ~~/)、[杭州](https://m.zhipin.com/zhaopin/2feb34b40323cf930nF62t26EA~~/)、[广州](https://m.zhipin.com/zhaopin/84e753ed302fbef31H193d68Fw~~/)、[成都](https://m.zhipin.com/zhaopin/e6edc20c9b8b6e0e03V62tm8Ew~~/)、[苏州](https://m.zhipin.com/zhaopin/e62ced1a0c5547ef0nR-3tm6Ew~~/)、[武汉](https://m.zhipin.com/zhaopin/870691b5c9322cf303V92NW4EQ~~/)、[西安](https://m.zhipin.com/zhaopin/1f95b1e31a4e39cc03Ny09W0Fg~~/)、[南京](https://m.zhipin.com/zhaopin/4b773679fb8ed36603162N20FA~~/)。
- 猎聘用于交叉验证，例如[深圳 AI Agent 智能体工程师](https://www.liepin.com/job/1972329243.shtml)、[杭州智能对话服务 P6](https://www.liepin.com/job/1983967513.shtml)和[西安资深 Agent 架构师](https://www.liepin.com/a/76744575.shtml)。
- 配套数据：[137 个岗位样本 TSV](./boss-agent-job-sample.tsv)。

## 统计结果

| 能力类别 | 全体可编码样本 / 122 | 资深可编码样本 / 38 | 对学习路线的影响 |
|---|---:|---:|---|
| Agent 核心：规划、工具、工作流、执行 | 113（92.6%） | 33（86.8%） | 必须精通，是 Agent 学习主线 |
| 工程化：后端、稳定性、扩展性、恢复 | 94（77.0%） | 36（94.7%） | 资深岗位第一优先级，持续验收 |
| 业务架构与端到端交付 | 54（44.3%） | 33（86.8%） | 用 ADR、SLO、容量和评审证明资深能力 |
| RAG、上下文、知识库、记忆 | 45（36.9%） | 13（34.2%） | 必须熟练到可量化评测 |
| 评测、优化、可观测性 | 32（26.2%） | 11（28.9%） | 不能只做功能 Demo |
| 推理部署、性能或高并发 | 19（15.6%） | 9（23.7%） | 在资深岗位更重要，保留完整推理基础线 |
| 模型训练、微调或后训练 | 18（14.8%） | 4（10.5%） | 掌握采用边界，不展开大规模训练 |
| 具体 Agent 框架 | 15（12.3%） | 2（5.3%） | 框架不是核心竞争力 |
| Tools/MCP 显式要求 | 14（11.5%） | 2（5.3%） | 协议名称低频不等于工具可靠性不重要 |
| 多 Agent | 9（7.4%） | 1（2.6%） | 学习适用边界和消融，不作为默认架构 |
| 安全、权限或治理 | 2（1.6%） | 0（0%） | 招聘摘要低估风险，仍是生产底线 |

经验分布：3–5 年 48/137，1–3 年 32/137，5–10 年 30/137；其余为经验不限、校招、1 年以内、5 年以上或未注明。

学历分布：本科 111/137，硕士 21/137，其他或未注明 5/137。硕士和 10 年经验已经满足多数硬门槛；需要重点证明的不是工作年限，而是能否把既有系统经验迁移为 Agent 架构、可靠性、性能和业务交付证据。

## 对个人路线的结论

1. 不按初级工程师路线从 Python 或框架教程开始；直接用原生实现补齐原理，再进入框架运行时和生产设计。
2. 资深岗位的工程可靠性为 94.7%、业务交付为 86.8%，阶段验收必须包含 ADR、SLO、容量、成本、故障和业务价值，不接受只有功能演示。
3. 推理/Serving 在资深岗位中的显式比例升至 23.7%，应完整补强 Transformer、KV Cache、性能指标、Serving 和推理优化。
4. 模型训练侧掌握 LoRA/SFT/DPO/RL 的目的、数据与评测边界，不在 16 周内展开分布式预训练。
5. 多 Agent 和具体框架在资深样本中分别只有 2.6% 和 5.3%；只做到能实现、能解释、能消融，不用它们替代系统设计能力。
6. 最终作品必须体现资深岗位信号：架构决策、SLO、容量/成本模型、评测集、威胁模型、故障恢复和技术评审表达。
